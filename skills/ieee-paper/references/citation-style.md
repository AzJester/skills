# IEEE reference style

Numbered in **order of first appearance in the text**, not alphabetically. Every reference cited; every citation listed.

## In-text citation

| Situation | Form |
| --- | --- |
| Normal | `…as shown in [1].` |
| Starting a sentence | `Reference [1] shows…` — never "[1] shows…" |
| Several, non-contiguous | `[1], [3], [5]` |
| A range | `[1]–[5]` |
| With a page or section | `[1, Sec. 3]`, `[2, pp. 45–47]`, `[3, Fig. 2]` |
| Author named in the sentence | `Author *et al.* [4] found…` |

The bracket sits inside the sentence's punctuation: `…in [1].` Not `…in [1] .` and not `…in.[1]`

Do not write "in Ref. [1]" or "in reference [1]" in running text — the bracket alone carries it.

## Author names

Initials first, then surname: `J. K. Author`.

| Count | Form |
| --- | --- |
| One | `J. K. Author,` |
| Two | `J. K. Author and A. B. Second,` |
| Three to six | `J. K. Author, A. B. Second, and C. D. Third,` |
| More than six | List the first, then `et al.` — check the venue, some list all |

`et al.` is italicised.

## Patterns by source type

**Journal article**
```
[1] J. K. Author, "Title of paper in sentence case," Abbrev. Journal Name,
    vol. 12, no. 3, pp. 123–135, Mar. 2024, doi: 10.1109/XXXXX.
```

**Conference paper**
```
[2] A. B. Author and C. D. Second, "Title of conference paper," in Proc. Abbrev.
    Conf. Name, City, Country, 2024, pp. 45–52.
```

**Book**
```
[3] J. K. Author, Title of Book in Title Case, 3rd ed. City, State/Country:
    Publisher, 2023.
```

**Chapter in a book**
```
[4] J. K. Author, "Title of chapter," in Title of Book, A. Editor, Ed. City:
    Publisher, 2023, pp. 100–120.
```

**Technical report**
```
[5] J. K. Author, "Title of report," Organization, City, Rep. TR-2024-01, 2024.
```

**Standard**
```
[6] IEEE Standard for Something, IEEE Standard 802.11, 2020.
```

**Thesis or dissertation**
```
[7] J. K. Author, "Title of thesis," M.S. thesis, Dept. Elect. Eng., Univ. Name,
    City, Country, 2023.
```

**Patent**
```
[8] J. K. Author, "Title of patent," U.S. Patent 1 234 567, Jan. 15, 2024.
```

**Website**
```
[9] Organization. "Page title." Site Name. https://example.com/page
    (accessed Mar. 15, 2024).
```

**Preprint**
```
[10] J. K. Author, "Title of preprint," 2024, arXiv:2401.12345.
```

**Dataset or software**
```
[11] J. K. Author, "Name of dataset," Repository, 2024. doi: 10.5281/zenodo.XXXX.
```

## Capitalisation

The rule that catches most drafts:

- **Article, paper, and chapter titles** → sentence case, in quotation marks. Only the first word, proper nouns, and the first word after a colon are capitalised.
- **Journal, conference, and book titles** → title case, italicised.

So: `"A study of deep learning for image classification," IEEE Trans. Pattern Anal. Mach. Intell.`

## Abbreviations

IEEE abbreviates journal and conference names to a standard list — `IEEE Trans. Pattern Anal. Mach. Intell.`, `Proc. IEEE Int. Conf. Comput. Vis.` Reference managers do this correctly when pointed at the IEEE style; abbreviating by eye produces inconsistency a copy editor will return.

Months abbreviate to three letters with a period: Jan., Feb., Mar., Apr., Jun., Jul., Aug., Sep., Oct., Nov., Dec. May is not abbreviated.

## Checks before submission

- Numbering follows first appearance in the text, with no gaps.
- Every entry is cited somewhere; every citation resolves to an entry.
- Article titles in sentence case; venue titles in title case and italic.
- DOIs present where available, and formatted consistently.
- Accessed dates on every web reference.
- No reference consisting only of a bare URL.
