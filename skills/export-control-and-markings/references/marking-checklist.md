# Pre-release checklist and marking patterns

Run before any document, file, model, dataset or presentation leaves your control — including internally to someone whose authorisation you have not confirmed.

## Checklist

**What is in it**
- [ ] Does it contain technical data about a controlled item, process or capability?
- [ ] Does it contain CUI, in any category?
- [ ] Does it contain another party's proprietary information, and are you permitted to include it?
- [ ] Does it contain contract-specific information the contract restricts?

**Who is receiving it**
- [ ] Are all recipients authorised for the content?
- [ ] Are any recipients foreign persons? (Nationality, not location — a deemed export happens domestically.)
- [ ] Does any recipient list, distribution group, or repository include people you have not enumerated?
- [ ] Will it be stored or transmitted through a service not approved for this content?

**What it needs on it**
- [ ] CUI banner markings, top and bottom of every page
- [ ] Designation indicator — who determined, under what authority
- [ ] Portion markings, where required
- [ ] Distribution statement with reason, date, and controlling office
- [ ] Export control warning, where applicable
- [ ] Classification markings, if classified — a separate process this checklist does not cover

**Approvals**
- [ ] Public release review completed, if Distribution A
- [ ] Export control review, if any doubt about control status
- [ ] Contract compliance — CDRL format and marking requirements met

**If any answer is uncertain: stop and ask before sending.**

## Marking block patterns

Exact wording is set by current policy and by the contract. Confirm against the authoritative source; these show the shape and the fields that must be present.

**CUI banner** — top and bottom of every page:

```
CUI
```

with limited dissemination controls appended where they apply.

**Designation indicator** — on the first page:

```
Controlled by:        [Organization / office]
Controlled by:        [Sub-office]
CUI Category:         [Category from the registry]
Limited Dissemination Control: [if any]
POC:                  [Name, contact]
```

**Distribution statement** — on the cover or first page:

```
DISTRIBUTION STATEMENT [A–F]. [Statement text].
[Reason]. [Date of determination].
Other requests for this document shall be referred to [controlling DoD office].
```

**Export control warning** — where applicable, alongside the distribution statement:

```
WARNING - This document contains technical data whose export is restricted
by [applicable statute]. Violations may result in severe criminal penalties.
```

## Common failures

| Failure | Why it happens |
| --- | --- |
| Distribution A applied with no release review | Treated as a default for unrestricted documents rather than as a determination |
| Markings added at send time | Drafts circulate unmarked; the marking arrives after the exposure |
| Legacy markings left in place | FOUO on an old document is not correct CUI marking today |
| Controlled data in an unapproved tool | Convenience, and no habit of asking before use |
| Access granted by group rather than by person | Nobody enumerated who is in the group |
| Foreign national colleague included by default | Deemed export not recognised as an export |
| Marking on the document, not on the file name or metadata | Content marked, container not |

The pattern behind most of these is the same: a default action taken without a pause. The checklist exists to insert the pause.
