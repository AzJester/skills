# TRL evidence sheet

One sheet per critical technology element. The evidence is the assessment; the number is shorthand for it.

## Element identification

| | |
| --- | --- |
| **Element** | |
| **Why it is critical** | Novel *and* a requirement fails without it — state both halves |
| **Requirement(s) it supports** | |
| **Owner** | |
| **Assessed by / date** | |

An element that is novel but not depended upon is not critical. One that is depended upon but mature is a dependency, not a technology risk. Both halves, or it does not belong on this sheet.

## Current assessment

| | |
| --- | --- |
| **Assessed TRL** | |
| **What was demonstrated** | Component / breadboard / prototype / actual system — and what it did |
| **Environment** | Laboratory / relevant / operational |
| **Stressors present** | |
| **Stressors absent** | |
| **Date demonstrated** | |
| **Evidence artifact** | Report number, test record, data location |

The two stressor rows decide the level. A demonstration claiming a relevant environment with an empty "absent" row has not been examined; a demonstration whose threatening stressors are all in the "absent" row is a laboratory demonstration however it is labeled.

## Application check

TRL is for *this* use, not the technology in general.

| | |
| --- | --- |
| Proven elsewhere at TRL | |
| How this application differs | Environment, scale, duty cycle, integration, data volume |
| Why those differences do or do not reduce the level | |

Heritage claims live or die on this section. An unexamined "it is already TRL 9 in industry" is the technology-maturity equivalent of an unargued similarity claim in verification.

## Assessor's note

State any disagreement about the level and its basis. A TRL argued down from 6 to 5 by a reviewer, with the reason recorded, is far more credible at the next gate than a 6 nobody challenged.
